# Requirements — KeyGuard Local

Requirement documents for the KeyGuard Local demo store. It sells fictional keypad-locked USB drives and is built with Streamlit and Supabase. **Start with document 00.**

| # | Document | What's inside | Main reader |
|---|---|---|---|
| 00 | [Consolidated requirements](00-consolidated-requirements.md) | One-page starting point: goals, roles, features, UI and NFR summaries, data model, scope, open questions, build order, traceability | Everyone |
| 01 | [Product features and user stories](01-product.md) | The product, catalog, business rules, domain terms, 31 user stories with acceptance criteria, end-to-end scenarios | Product, developers, testers |
| 02 | [UI / UX requirements](02-ui-ux.md) | Vision analysis, gaming/RGB visual system, wireframes, user flows, screens S1–S16, system states, Streamlit limits, designer deliverables | Designer |
| 03 | [Non-functional requirements](03-non-functional-requirements.md) | Sign-in, security, privacy and child safety, data integrity, performance, accessibility, environments, limits, constraints and assumptions | Developers, reviewers |
